# Qavonia — Independent Video Discovery & Digital Media Resource

**Project website:** https://qavonia.com/

This repository contains an independent set of reader-focused resources about evaluating online video experiences, privacy, accessibility, and playback usability. The associated website is [Qavonia](https://qavonia.com/).

## Start here

The public resource site is published with GitHub Pages:

- [English resource homepage](https://spermandoodb-spec.github.io/qavonia-seo-resource/)
- [Spanish-language resources](https://spermandoodb-spec.github.io/qavonia-seo-resource/es/)

## Topics

- Evaluating video platforms: performance, navigation, transparency, and usability
- Privacy and account safety
- Accessibility, captions, and keyboard operation
- Practical playback troubleshooting

## Repository structure

- `site/` — static website published through GitHub Pages
- `docs/` — editable source guides
- `es/` — Spanish-language source resources
- `EDITORIAL-STANDARDS.md` — publishing and quality principles

## Editorial standards

Content should solve a real reader problem, use clear language, and avoid unsupported claims. Links are included only when they are relevant and clearly described. This project does not publish scraped pages, fabricated reviews, hidden links, or mass-produced doorway pages.

## Independence and disclosure

This is an independently maintained resource project. A link to Qavonia identifies the associated website; it does not imply third-party endorsement, certification, or partnership. Service-specific privacy, billing, or content claims should always be checked against the relevant provider's own documentation.
