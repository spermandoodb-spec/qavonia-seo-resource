# Accessibility and Playback Usability

Accessible video experiences support different devices, input methods, and access needs.

## Captions

Captions should be synchronized and accurate. Include meaningful sound information and speaker identification where appropriate.

## Keyboard access

Player controls should be reachable and operable without a mouse. Focus should remain visible and predictable.

## Responsive presentation

Use readable text, sufficient contrast, and usable touch targets. Check common mobile widths and orientation changes.

## Troubleshooting safely

For playback problems, check the network, reload once, update the browser, temporarily test without conflicting extensions, and try another supported device. Do not install unknown codecs or executable updates from pop-ups.
